使用说明

1. 登录

使用分配的账号密码登录系统。

默认账号: admin / admin123

2. 提交爬取任务

  1. 进入「首页」
  2. 在文本框中粘贴Amazon商品链接，支持多个链接（每行一个）
  3. 支持以下格式:
    • 商品页: https://www.amazon.com/.../dp/B0XXXXX/
    • 评论页: https://www.amazon.com/product-reviews/B0XXXXX/
    • 纯ASIN: B0XXXXX
  4. 点击「开始爬取」
  5. 系统会自动解析链接并创建爬取任务

3. 查看任务状态

任务列表显示所有爬取任务的状态:

  • pending - 等待中
  • running - 爬取中
  • completed - 已完成
  • failed - 失败

页面会自动刷新更新状态

4. 查看评论列表

在「评论列表」页面可以:

  • 查看所有爬取的评论
  • 按ASIN筛选特定商品
  • 按评分范围筛选
  • 分页浏览

5. 数据分析

「数据分析」页面提供:

  • 基础统计 - 总评论数、商品数、平均评分
  • 评分分布 - 各星级评论数量占比
  • 情感分析 - 正面/中性/负面评论比例
  • 关键词分析 - 好评和差评中的高频词
  • 时间趋势 - 按月份的评论数量和评分变化

6. 导出数据

在评论列表页面可通过筛选后下载CSV文件，用Excel进一步分析。

注意事项

  • 爬取过程在后台进行，页面会自动刷新更新进度
  • 如果检测到验证码，任务会标记失败
  • 建议合理控制爬取频率，避免被限制
  • 数据仅存储在本地服务器
