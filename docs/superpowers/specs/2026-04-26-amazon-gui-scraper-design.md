# Amazon 差评采集工具 (GUI版) 设计文档

## 目标

为不懂编程的用户提供一款桌面工具，通过图形界面采集亚马逊商品评论数据。

## 用户场景

- 用户提供商品链接或评论链接列表
- 程序自动采集所有评论数据
- 用户通过 GUI 监控进度，结束后查看结果文件

## 三、功能详情

### 3.1 链接输入

| 输入方式 | 说明 |
|----------|------|
| 文本框输入 | 每行一个链接，支持商品页或评论页 |
| 文件导入 | 支持 .txt、.csv，每行一个链接 |

**链接自动识别：**
- 商品页 (`/dp/ASIN/` 或 `/gp/product/ASIN/`) → 自动拼接评论页 URL
- 评论页 (`/product-reviews/ASIN/`) → 直接使用
- ASIN 提取 → 用于数据存储

### 3.2 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 最小请求间隔 | 8 秒 | 随机间隔的下限 |
| 最大请求间隔 | 15 秒 | 随机间隔的上限 |
| Cookie 文件 | cookies.json | 登录态文件路径 |
| 代理模式 | 系统代理 | 两种模式可选 |
| 手动代理 | 无 | 格式: ip:port:user:pass |

**代理模式说明：**
- **系统代理** — 读取 Windows 系统代理设置（适用于 VPN 用户）
- **手动输入** — 用户直接输入代理地址，格式 `ip:port:username:password`

### 3.3 采集逻辑

```
1. 解析输入链接，提取 ASIN
2. 检查断点文件（支持中断恢复）
3. 遍历每个 ASIN：
   a. 检查是否已采集（断点续采）
   b. 随机等待间隔（8-15秒）
   c. 分配代理（系统代理或手动代理）
   d. 打开评论页
   e. 检测验证码 ← 暂停并提示用户
   f. 加载所有评论（分页滚动）
   g. 提取所有评论数据
   h. 存入数据库
   i. 更新断点记录
4. 完成通知
```

### 3.4 断点续采

**实现方式：**
- 每次成功采集完一个链接后，记录已完成的 ASIN 到 `progress.json`
- 中断后重新启动时，自动跳过已完成的 ASIN
- 支持随时停止，保留进度

**进度文件格式 (progress.json)：**
```json
{
  "total": 10,
  "completed": ["B0FMNCV88Q", "B0XXXXXXX"],
  "last_updated": "2026-04-26 10:30:00"
}
```

### 3.5 数据提取

**字段：**
- `asin` — 商品 ASIN
- `rating` — 评分（1-5 星）
- `date` — 评论日期
- `content` — 评论内容
- `is_vine` — 是否 Vine 评论
- `collected_at` — 采集时间

**存储：** SQLite 数据库 (`amazon_reviews.db`)

### 3.6 反爬措施

| 措施 | 实现 |
|------|------|
| 随机 UA | 每次请求从 10+ Chrome UA 池随机选取 |
| 指纹隐藏 | 覆盖 webdriver、WebGL、Canvas、timezone、language 等 8 项 |
| 验证码检测 | 检测到 CAPTCHA 页面时暂停，弹窗提示用户 |
| 请求限速 | 随机 8-15 秒间隔（可配置） |
| Cookie 管理 | 支持加载外部 Cookie，过期提示重置 |

### 3.7 进度与日志

| 显示项 | 说明 |
|--------|------|
| 链接进度 | X/Y 链接已处理 |
| 评论计数 | 已采集 N 条评论 |
| 进度条 | 百分比可视化 |
| 实时日志 | 每条操作记录滚动显示 |

### 3.8 完成后操作

- 显示结果文件路径（数据库文件）
- 提供「打开文件夹」按钮
- 可扩展：导出 CSV 功能

## 八、风险提示

1. **验证码** — 亚马逊可能触发 CAPTCHA，需用户手动处理
2. **IP 封禁** — 连续大量请求可能导致 IP 被封，建议启用 VPN
3. **页面结构变化** — 亚马逊改版可能导致选择器失效
4. **Cookie 过期** — 登录态 Cookie 有时效性，过期需重新导入
