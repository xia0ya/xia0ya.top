# Amazon 评论爬虫 Web 服务设计

**日期**: 2026-04-29
**状态**: 已批准

## 概述

为业务人员提供简易的 Amazon 评论爬取和分析工具。通过网页界面，无需代码即可完成链接提交、数据爬取、评论分析和导出。

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | FastAPI | 复用现有爬虫逻辑 |
| 前端 | Jinja2 + TailwindCSS | 轻量模板 + 少量JS |
| 数据库 | SQLite | 复用现有 `database/store.py` |
| 认证 | Session/Cookie | 用户名密码登录 |

## 用户故事

- 业务人员打开网页，使用账号登录
- 粘贴 Amazon 商品链接（支持单个或批量）
- 系统自动提取ASIN，后台启动爬虫任务
- 业务人员可查看任务进度、评论列表
- 在网页上查看分析报告（统计、关键词、情感、时间趋势）
- 支持下载CSV继续用Excel分析

## 页面结构

| 路径 | 功能 |
|------|------|
| `/login` | 登录页 |
| `/logout` | 登出 |
| `/dashboard` | 首页：提交链接、查看任务列表 |
| `/reviews` | 评论列表：按商品/评分/日期筛选 |
| `/analytics` | 数据分析：统计、关键词、情感、时间趋势 |
| `/export` | 导出CSV |

## 功能详情

### 1. 登录认证
- 用户名 + 密码登录
- Session保持在Cookie中
- 登出清除Session

### 2. 链接提交（Dashboard）
- 文本框支持粘贴单个或多个链接（每行一个）
- 系统自动解析ASIN
- 显示解析结果（成功/失败）
- 提交后创建爬虫任务
- 任务列表显示：ASIN、商品名、状态（pending/running/completed/failed）、评论数、时间

### 3. 爬虫任务
- 后台异步执行（避免请求超时）
- 复用现有 `ReviewPageController` 和 `ReviewExtractor`
- 支持同时运行多个任务（队列管理）
- 异常处理：验证码、代理失败、超时

### 4. 评论列表
- 分页展示
- 筛选条件：ASIN、评分范围、日期范围
- 显示字段：ASIN、评分、日期、内容、Vine标识

### 5. 数据分析（Analytics）
- **基础统计**：总评论数、总商品数、平均评分、评分分布图
- **关键词分析**：提取评论中的高频词，好评/差评分别统计
- **情感倾向**：正面/负面/中性分类（基于关键词规则）
- **时间趋势**：按月份的评论数量和平均评分趋势

### 6. 数据导出
- 支持按ASIN或时间范围筛选
- 下载CSV格式
- 字段：ASIN、评分、日期、内容、Vine

## 数据库

复用现有 SQLite 结构：
- `products` 表：存储商品信息
- `reviews` 表：存储评论数据

新增用户表：
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 无效链接 | 提示"无法识别的链接" |
| 验证码 | 标记任务失败，提示"检测到验证码" |
| 代理失败 | 重试3次，仍失败则标记失败 |
| 网络超时 | 标记任务失败，可重试 |
| 未登录访问 | 重定向到登录页 |

## 部署

- 前端 Nginx 代理静态文件 + 反向代理 FastAPI
- 内网穿透/域名绑定实现外网访问
- 进程管理：systemd 或 supervisor

## 验收标准

1. 业务人员无需代码即可完成完整爬取流程
2. 登录状态下可以保存Session
3. 评论数据支持网页筛选和导出
4. 分析页面展示4类分析结果
5. 内网环境下可正常运行
